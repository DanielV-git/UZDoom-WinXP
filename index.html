UZDoomXP

An UZDoom WinXP Port for old gaming machines running Windows XP.

About the Project

This UZDoom backport targets vintage gaming rigs that will stay on Windows XP. It actively backports modern API implementations used in the main UZDoom repository, giving retro operating system native access to the latest source developments.
